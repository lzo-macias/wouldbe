CSS 02 — Proportional grid columns (the StartAWouldBe 3-up)

Three columns whose widths keep the ratio 305 : 280 : 377 while the row stretches to full width — and all three are the same height (the tallest drives it). Use grid-template-columns: 305fr 280fr 377fr (fr = a share of the leftover space) with a gap, and align-items: stretch. In columns 2 & 3, pin the first item to the top and the last to the bottom with justify-content: space-between. Edit 02-grid-fr-columns.css under .yours.
