CSS 01 — Two-column flex split (the WouldBe layout)

Build a fixed left panel + flexible right feed, matching Target. Rules: the panel is exactly 160px and never shrinks; the feed takes the rest and its long URL must wrap instead of pushing the layout wider. The trick that makes wrapping work: a flex item defaults to min-width:auto (won't shrink below its content) — set min-width:0 so it can. Edit 01-flex-split-minwidth.css; style only under .yours.
