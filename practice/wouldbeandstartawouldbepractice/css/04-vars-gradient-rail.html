CSS 04 — Progress rail from a CSS variable (the timeline rail)

The gold "how far to Today" rail is ONE gradient whose fill point is a variable the React code sets inline: style={{ '--progress': '57%' }}. Recreate it: a linear-gradient(90deg, …) that is gold from 0 to var(--progress) then gray from var(--progress) to 100%. Two color stops at the SAME position make a hard edge (no blend). Define --gold and --track once on .yours and reference them with var(). The per-rail --progress is already set inline on each bar. Edit 04-vars-gradient-rail.css.

Target

--progress: 30%
--progress: 57%
--progress: 90%
