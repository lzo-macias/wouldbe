CSS 03 — Absolute positioning (timeline pin, YOU flag, corner chip)

On a position:relative card, place four positioned children (matching Target): a goal chip in the top-right corner; a horizontal rail inset 18px on each side; a rose marker dot centered on the rail at 40% across; and a YOU bubble centered above it. Key move: an absolute child is placed relative to the nearest position:relative ancestor. To CENTER on a point, put its edge at the point (left:40%) then pull it back half its own size with transform: translateX(-50%) (or translate(-50%,-50%) for both axes).
