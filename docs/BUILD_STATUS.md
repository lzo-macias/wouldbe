## Biggest remaining chunks (suggested priority)

1. **§6 Debates + Debate Update economics** — the other half of the product; depends on Sponsors (§6) + payments (§13) + Twitch (§16). Highest surface area.
2. **§8 Posts/Endorsements/Comments** — core social loop; needs media upload (R2 presigned).
3. **§17 Notifications engine** — unblocks the real `getRecommendedWouldbes` scorer and the `*_reached` emissions already stubbed in §5.
4. **§13 Payments (Stripe) + §14 Tax** — real-money surfaces (tips, debate fees/markup, payouts, 1099/1042-S).
5. **§10–§11 Moderation + Trust & Safety** — required before public content.
6. **§16 crons/webhooks** — wire the calendar-sync / link-health / stage-gate jobs the DB layer already supports.

**Money model (confirmed):** the platform never touches campaign contributions (pledges are promises only). Platform revenue = tips + debate-poster flat fee + a per-transaction markup on debate transactions.
